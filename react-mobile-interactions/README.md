# React mobile interactions moved to Moggridge

The library now lives in **[splitintech/moggridge](https://github.com/splitintech/moggridge)**.

Moggridge combines the original swipe, back-layer and navigation APIs with the
cross-platform motion catalog, card-motion studies, web and native adapters,
examples, tests and documentation. Relevant Git history and the original banner
were preserved in the new repository.

The npm name remains **`@splitin/react-mobile-interactions`**. Existing npm releases
and imports are unchanged. New development, issues, build instructions and releases
belong in Moggridge. This folder is a migration notice, not a package checkout.

- [README and installation](https://github.com/splitintech/moggridge#readme)
- [Motion lab](https://github.com/splitintech/moggridge#run-the-motion-lab)
- [Migration provenance](https://github.com/splitintech/moggridge/blob/main/docs/migration.md)
- [Publishing](https://github.com/splitintech/moggridge/blob/main/docs/publishing.md)

The source candidate is not automatically published to npm by this migration.
